# Unstructured Food Input

A web application for processing unstructured food input.

## Getting Started

### Prerequisites
- Node.js
- Python 3.x

### Clone the Repository
```bash
git clone <repository-url>
cd unstructured-food-input
```

### Run the Frontend
```bash
npm install
npm run dev
```

### Run the Backend Server
```bash
pip install -r requirements.txt
uvicorn server:app --reload
```

 Note: The frontend and backend servers must be running concurrently for the application to function properly.
